## 🏗️ Technical Overview

**PlanYourFuture** is a complete **PERN stack application** built using:

- PostgreSQL
- Express.js
- React
- Node.js
- Docker
- Coolify deployment
- Playwright testing

The application provides users with a structured way to create, manage, and share development goals with mentors.

### Key Features

### 🔐 Authentication & Security

- Implemented secure user registration and login functionality.
- Used JWT-based authentication to manage protected user sessions.
- Designed secure access control between users and mentors.

### 📋 Goal and Task Management

- Built a dynamic dashboard allowing users to:
  - Create goals.
  - View goals.
  - Update goals.
  - Delete goals.
  - Track development progress.

### 🤝 Goal Sharing & Mentorship Workflow

- Developed a plan-sharing system where users can select specific goals to share publicly.
- Enabled mentors to review shared development plans.
- Created a feedback loop where mentor advice appears directly on the user's private dashboard.

### 🧪 Testing & Quality Assurance

- Developed an End-to-End testing suite using Playwright.
- Improved confidence in application reliability through automated testing.
- Followed professional development practices focused on maintainability and quality.

### 🚢 Deployment & Infrastructure

- Containerised the application using Docker.
- Worked with deployment workflows using Coolify.
- Applied modern software delivery practices from development to production.
